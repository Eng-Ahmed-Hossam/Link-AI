# Go-live switches

Every local fake in Link, and what replaces it for real users. Every path and environment name below was checked against the code on 2026-10-09; when a row says "to build", that piece of code doesn't exist yet. Provider names are candidates **to compare**, not choices ([provider choice](plan/provider-choice.md) compares them). Paperwork and owners: [before real users](plan/before-real-users.md). Privacy rules: [docs/10](10-security-privacy.md).

**How a switch works.** core-api reads one `*_PROVIDER` setting per outside service (`apps/core-api/src/config.ts`). A provider called `fake` is **refused when `APP_ENV=prod`**, so production can't start on a fake by accident. Behind every provider sits one interface in `apps/core-api/src/adapters/`; a real provider is one new class implementing it, and nothing else in the app changes.
