# جولة الدفعة ٥ — تطبيق المعلّم (المرحلة ٢)

بيانات تجريبية فقط (سيناريو `demo-followup`). لا يوجد مزوّد حقيقي ولا صوت حقيقي لأي شخص.
الصور تُنتَج تلقائيًا من الاختبار `apps/teacher-app/e2e/walkthrough.spec.ts` على نسخة الويب من التطبيق، مع خادم البيانات التجريبية المشترك (`pnpm demo`).

## التشغيل

```bash
pnpm demo          # خادم البيانات التجريبية + الويب + تطبيق المعلّم (Expo web على 8081)
pnpm --filter @link/teacher-app test:e2e   # يعيد إنتاج هذه الصور والملف JSON
```

## الدليل من الخادم

`consecutive-absences.json` هو ناتج `GET http://localhost:4010/__demo/state/ar` مباشرة بعد التأكيد: تنبيه `consecutive_absences` (الإصدار ١) لمريم حسن، بدليلَي السجلَّين المؤكَّدين (٣٠ سبتمبر و٣ أكتوبر في هذا التشغيل)، ومتابعة مُسندة إلى الاستقبال (دينا عادل) ومستحقة في نفس اليوم، و`confirmCommits = 1`. تنبيه نور خالد كان موجودًا من قبل في السيناريو.

> ملاحظة: التواريخ تُحسب من تاريخ اليوم عند تشغيل السيناريو، لذلك تختلف بين التشغيلات.
