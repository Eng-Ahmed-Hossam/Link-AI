# Private real voice notes

This folder is ignored by git except for this README. Store **consented real notes only**, with consent captured in the approved private store and the collection/transfer approvals required by the project. Synthetic script recordings should use the private audio folder described in [the recording guide](../RECORDING_GUIDE.md).

For each approved note, keep the original audio, a private roster, a transcript written and checked by humans, independently annotated person-name occurrences and structured facts, and private recording metadata. Use an opaque note ID and speaker ID. Gold annotations must be written without looking at the pipeline predictions. Review ambiguous/unknown names explicitly; keep them unassigned, preserve scores outside the assessment range, and leave unmentioned students not recorded.

Never commit audio, real transcripts, consent records, real rosters, guardian contacts, or identifying metadata. The tracked synthetic JSON files are examples of the annotation shape, not permission to publish a real note. Apply the project's access and retention rules to private evaluation artifacts.
