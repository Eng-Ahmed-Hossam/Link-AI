## Reading and annotation notes

Read only the Arabic paragraph. Do not read IDs, tags, roster, punctuation names, or metadata. Say digits as natural numbers; keep the Arabic/English subject terms. Fast = brisk but intelligible, slow = deliberate; avoid acting or exaggerating noise. Aim for 20–60 seconds, with target times as guidance rather than measured durations.

Offsets in JSON refer to the original reference_transcript, Unicode code points, end exclusive. Repeated people have separate mention occurrences. Safe full names and documented nicknames resolve; shared first names remain ambiguous. Candidate IDs identify mentioned possible students, so expected_unmentioned excludes those candidates. This does not permit automatic records for them. Unknown adults have privacy mentions but no student facts. Corrected/abandoned name mentions remain tokenised; only the final corrected statement supplies facts. Observation values preserve the source wording; tags are human labels for later LLM evaluation. The deterministic rule baseline is expected to omit observations and may abstain on corrections.
